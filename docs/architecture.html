✏️ Real-Time Collaborative Editing Flow
1
Monaco onChange Event
User types in Monaco editor → updates local code state → schedules debounced sync (120ms).
2
Socket code-change Emit
Client transmits { roomId, code, language } to backend socket server with user identity.
3
Backend Validation & Persistence
Backend verifies caller has 'owner' or 'editor' role → updates Room document in MongoDB asynchronously.
4
Broadcast code-update
io.to(roomId).except(senderSocketId).emit("code-update") → remote peers update buffer without losing cursor position.
⚡ Sandboxed Execution with Stdin Pipeline
1
Frontend Stdin Capture
User provides input in 'Input (stdin)' tab → clicks Run → switches tab to 'Output' and calls POST /api/execute.
2
Rate Limit & Daily Quota Check
Express checks 5 req/min rateLimiter + checks MongoDB DailyExecution. If remaining <= 0, returns 429 quota error.
3
Judge0 Base64 Execution
Encodes source_code and stdin into Base64 → POST /submissions?base64_encoded=true&wait=true → decodes stdout/stderr/compilation errors.
4
Atomic Usage Increment & Global Broadcast
DailyExecution $inc: 1 → io.emit("execution-usage") broadcast to ALL users globally → io.to(roomId).emit("execution-result").
🖱️ Real-Time Multi-Cursor Synchronization
1
Monaco onDidChangeCursorPosition
Detects cursor caret / line / column movements inside Monaco editor.
2
Client-side Throttle (100ms)
Prevents socket flooding by throttling cursor emissions to maximum 1 update per 100ms.
3
Monaco Delta Decorations
Remote clients receive cursor_update → renders custom CSS flag badge with peer's name & color-coded cursor bar.
🚪 Room Exit, Grace Period & Owner Handover
1
Exit Confirmation Guard
User clicks Exit button or hits browser Back (popstate) → window.confirm() dialog prevents accidental loss.
2
5-Second Disconnect Grace Period
On socket disconnect, presenceStore waits 5000ms. If user reloads or reconnects within 5s, room state is preserved.
3
Automated Next-Owner Election
If owner permanently leaves: pickNextOwner() promotes the next active senior member to 'owner' and notifies room.

⚡ Platform-Wide Quota Architecture
Atomic Operations: Uses findOneAndUpdate({ date }, { $inc: { count: 1 } }, { upsert: true }) to prevent race conditions during concurrent runs.
Global Synchronization: Backend uses io.emit("execution-usage") to update all connected sockets across all rooms simultaneously in real-time.
